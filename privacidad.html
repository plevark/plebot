Política de Privacidad de Plebot

Última actualización: 15 de noviembre de 2026

1. Información general

Plebot es un asistente de inteligencia artificial desarrollado por plevark. Esta política de privacidad explica cómo se recopila, usa y protege la información cuando utilizas nuestra aplicación y su integración con la API de Pinterest.

2. Datos que recopilamos

Plebot no recopila datos personales identificables de forma automática. Sin embargo:

  • Mensajes del chat: Los mensajes que envías a Plebot se procesan temporalmente para generar una respuesta, pero no se almacenan de forma permanente ni se comparten con terceros.
  • API Keys: Si generas una API Key, se almacena de forma segura en nuestra base de datos (Cloudflare D1) únicamente para validar tu acceso al servicio.
  • Búsquedas en Pinterest: Cuando usas la función de búsqueda de Pinterest, tu consulta se envía a la API de Pinterest para obtener resultados. No almacenamos esas búsquedas.

3. Uso de la información

La información se utiliza exclusivamente para:

  • Generar respuestas del asistente de IA.
  • Validar el acceso mediante API Keys.
  • Realizar búsquedas en Pinterest cuando el usuario lo solicita.

4. Compartición con terceros

Plebot utiliza servicios de terceros para funcionar:

  • Groq: Para el procesamiento de lenguaje natural del asistente de IA.
  • Pinterest API: Para realizar búsquedas de imágenes y Pines cuando el usuario lo solicita.
  • Cloudflare: Para alojar el Worker y la base de datos de API Keys.

No vendemos, alquilamos ni compartimos tu información personal con terceros con fines publicitarios.

5. Seguridad

Las API Keys se almacenan de forma encriptada en Cloudflare D1. Las credenciales de servicios externos (como Groq y Pinterest) se guardan como secretos encriptados en Cloudflare Workers y nunca se exponen públicamente.

6. Cookies y almacenamiento local

Plebot puede usar localStorage en tu navegador para recordar tu API Key y evitar que tengas que generarla de nuevo cada vez que recargues la página. Esta información se guarda únicamente en tu dispositivo y no se envía a nuestros servidores.

7. Derechos del usuario

Como usuario, tienes derecho a:

  • Dejar de usar el servicio en cualquier momento.
  • Solicitar la eliminación de tu API Key.
  • Consultar qué datos (si alguno) tenemos sobre ti.

8. Cambios en esta política

Podemos actualizar esta política de privacidad ocasionalmente. Cualquier cambio será publicado en esta misma página con la fecha de actualización correspondiente.

9. Contacto

Si tienes preguntas sobre esta política de privacidad, puedes contactarnos a través de:

  • Repositorio de GitHub: github.com/plevark/plebot

Al usar Plebot, aceptas los términos descritos en esta política de privacidad.
